固件在线升级

无需安装驱动和工具，浏览器直接完成固件烧录。支持单频版（2.4G）/ 双频版（2.4G+5G），烧录地址统一为 0x20000。

⚡

无线安全审计工具固件 v2.1

将设备通过 Type-C 连接电脑，点击下方按钮，选择设备端口即可开始烧录。

您的浏览器不支持 Web Serial，请使用 Chrome 或 Edge（桌面版）打开此页面。
升级步骤：
1️⃣ 用 Type-C 数据线将设备连接电脑
2️⃣ 点击「升级固件」按钮，首次使用需授权串口
3️⃣ 选择设备端口，等待烧录完成（请勿断开设备）
提示：需通过 HTTPS 访问并使用支持 Web Serial 的浏览器（Chrome / Edge）。
