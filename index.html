// Firmware Update

固件在线升级

设备通过 Type-C 连接电脑，直接在浏览器中完成固件烧录，无需安装任何驱动和工具。

无线安全审计工具固件

当前版本 v2.1 · 烧录地址 0x20000

支持单频 / 双频两种版本，升级前请先确认设备版本。

当前浏览器不支持 Web Serial，请使用 Chrome / Edge 浏览器（桌面版）打开本页面。
需要 HTTPS 访问 + Chrome/Edge 浏览器 · 烧录地址 0x20000

📶 支持版本

单频版 · 2.4G 双频版 · 2.4G+5G

两种版本使用同一份固件包，烧录地址统一为 0x20000，浏览器自动识别芯片（ESP32-C3 / ESP32-C5）。

📋 升级步骤

1用 Type-C 数据线将设备连接电脑
2点击左侧「升级固件」按钮
3选择设备端口，等待烧录完成
