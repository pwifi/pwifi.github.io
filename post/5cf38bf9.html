hashcat 安装与 WPA/WPA2 破解命令笔记

掩码破解 / 字典破解 / 字典加规则 / 掩码文件 / 任务还原，速查手册。

安装

git clone https://github.com/hashcat/hashcat.git && cd hashcat && make -j 8 && make install

8到10位掩码破解

hashcat -a 3 --session=wifi -m 22000 -w 4 -p : --hwmon-disable -o password.txt --outfile-format=1,2 -i --increment-min=8 --increment-max=10 wifi.hc22000 ?d?d?d?d?d?d?d?d?d?d

字典破解

hashcat -a 0 --session=wifi -m 22000 -w 4 -p : --hwmon-disable -o password.txt --outfile-format=1,2 wifi.hc22000 字典.dic

字典加规则

hashcat -a 0 --session=wifi -m 22000 -w 4 -p : --hwmon-disable -o password.txt -r 规则.rule --outfile-format=1,2 wifi.hc22000 字典.dic

掩码文件

hashcat -a 3 --session=wifi -m 22000 -w 4 -p : --hwmon-disable -o password.txt --outfile-format=1,2 TP-wifi.hc22000 掩码文件.hcmask

还原操作方法

假设您使用此命令行启动破解作业：

hashcat -a 0 --session=wifi -m 22000 -w 4 -p : --hwmon-disable -o password.txt --outfile-format=1,2 wifi.hc22000 字典.dic

你在它运行时点击了“c”（或“q”表示退出）（或者由于其他原因被停止/杀死）。此命令恢复上述破解作业：

hashcat --session=wifi --restore

–restore 命令不需要也不允许任何其他参数，除了 –session（和 –restore 本身和 –restore-file-path）。还原作业时，不能简单地添加或更改某些参数。如果你真的坚持要改变任何论点，你可能会使用一些外部工具（如analyze_hc_restore），风险自负。
